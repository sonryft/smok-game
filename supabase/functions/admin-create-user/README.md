Despliegue con Supabase CLI:
1. Inicia sesión con Supabase CLI y enlaza el proyecto nuevo.
2. `supabase functions deploy admin-create-user`
3. Define los secretos del servidor: `SUPABASE_URL`, `SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY`.
La clave `SUPABASE_SERVICE_ROLE_KEY` nunca debe estar en archivos públicos ni en GitHub.
